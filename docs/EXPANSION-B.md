# B 区扩展实施与验收

用户已选择 B：中心城区约 68.7 km²，边界 WGS84 `[121.440,31.200,121.540,31.265]`，包含水域，延续桌面端、真实平面布局、四种模式及双向连续隧道驾驶。0.1.1 的 10 米洞宽继续保留。

1. **地理与范围**：从固定 OSM 缓存重建全部范围，纳入静安寺、南京西路、淮海中路、田子坊、南浦大桥地面周边、源深以及原有区域；道路裁切到边界，剔除未核验的高架／跨江桥面。新增 4 处专门制作的地标／街区：静安寺、上海博物馆人民广场馆、上海展览中心、田子坊里弄。原有 8 地标保留。地点与地区均可搜索、跳转。
2. **查询、加载、远景**：对道路段建立空间索引，驾驶只采样附近表面；500 米楼宇块保持加载门禁和碰撞邻区，近景立面与远景简模分离。街树、行人和车流在新区域仍有分布，不以全局截断方式只保留旧区。
3. **画面与操作**：新增地标以外观轮廓表达，缺失尺寸与里弄布局标注视觉估算；地图覆盖新边界、正确显示城区信息，地点菜单可滚动。保持原有昼夜、地图、四模式、相机与隧道操作。
4. **验证与交付**：自动检查范围、排重、河面、层级、索引正确性与查询规模、碰撞与加载。Tabbit 实测新目的地跳转、搜索不触发驾驶、四模式及新城区长路段、双向隧道；原有性能阈值保持 P95≤33.3ms、冷启动三次中位≤15秒。记录原始采样、固定视角、资源往返及连续稳定性，构建 0.2.0 静态包和源码包并验证独立运行、数据再生与构建一致。

南浦大桥附近开放的是地面城区，桥面驾驶不属于本次已选择范围；跨江行驶继续使用已实现的延安东路隧道。源缓存缺少完整原 OSM ID、单行和层级标签等既有数据限制继续记录，不把推测标签写成已核验事实。
