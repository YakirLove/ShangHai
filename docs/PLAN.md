# 上海中心城区交付合同

依据用户批准的实施计划及随后选择的 B 档扩区执行。本文件是当前范围；早期计划中的“首版不含桥隧驾驶”已废止。原始首版验收及 0.1.1 加宽记录保留，B 区执行记录见 [EXPANSION-B.md](EXPANSION-B.md)。

## 交付范围

桌面端优先，真实平面布局，原站 Slop New York 的程序立面、玻璃、光照、角色、车辆和镜头画风。覆盖外滩、陆家嘴、黄浦江、苏州河口及延安东路隧道两端必要道路。B 区边界 WGS84 `[121.440,31.200,121.540,31.265]`，含水域共 68.66 km²；新增静安寺、南京西路、淮海中路、田子坊、北外滩、南浦大桥地面周边与源深。

步行、汽车、自行车、直升机，三种相机、小地图、全屏地图、中文搜索、地标跳转，以及白天、黄昏、夜间。普通楼宇区分玻璃办公、住宅、沿街商业、历史街墙，配基本车流、行人、树木、路牌与夜景。

12 个地标：东方明珠、上海中心、环球金融中心、金茂大厦、上海国际会议中心、海关大楼、原汇丰银行大楼、和平饭店，以及静安寺、上海博物馆人民广场馆、上海展览中心、田子坊里弄。另有7个街区目的地。普通建筑不得重复生成地标。

连续双向驾车过江是必需项：外滩地面道路—延安东路—延安东路隧道—世纪大道／真实出口支路—陆家嘴道路。驾驶中不传送、不刷新、不黑屏切场。隧道中保持汽车模式，出洞后恢复模式切换。

不包含 B 区之外的城区、南浦大桥桥面驾驶、手机正式适配、建筑内部、多人玩法及本次公开上线。双向延安东路隧道采用 10 米游戏洞宽，缺失高程与宽度均为标记过的视觉估算。

## 实施与接口

固定上游源码版本；上海数据离线加工，全部资源自托管。局部米制坐标唯一投影入口；道路、水体、建筑和地标统一坐标。普通建筑和缺失的地下高程可视觉估算，必须保留来源标记。

- `SurfaceProvider.sample({x,z,y,mode,surfaceId})` 返回高度、法线和所属表面，分离地下与地面。
- `CollisionWorld.query(bounds)` 使用含 minY/maxY 的三维范围，城市块可加入、移除。
- `TileLoader.ensureAt(position,mode)` 在目标地形和碰撞就绪后完成。
- `TileLoader.ensureRoute(routeId)` 预载并驻留完整跨江路线；失败时保留当前有效位置并允许重试。

初始城市块 500 米，普通楼宇实例化，远景简化；车辆按道路表面高度和坡度行驶。地下相机可低于世界零点，受洞壁与顶板约束。

## 验收条件

参考设备：MacBook Pro / Apple M2 Pro / 16 GB，Tabbit Chromium、WebGPU、中档、实际画布 1920×1080、renderer DPR=1。报告必须记录实际浏览器版本。

| 类别 | 必须证明的结果 |
|---|---|
| 地理 | 河岸方向、江弯与苏州河口正确；至少 20 控制点对选定源坐标偏差 ≤5 米，另记源数据误差 |
| 地标 | 12 个齐全且无重复；四座主要塔楼可凭轮廓辨认；新增四处具有不同外形；位置与源坐标一致，估算尺寸和街块适配明确标注；近／远对照 |
| 画风 | 对照上游体量、窗格玻璃、光影、密度、水面夜景；原6机位×3时段18截图，另加5个新机位×3时段15截图 |
| 驾驶 | 双方向各3次，含白天和夜间；连续进出，无传送、穿墙、浮江或镜头穿顶；路面接缝 ≤0.1米；完整录屏与轨迹 |
| 分层 | 地面与隧道互不串层，地面建筑不误挡地下车辆，坡道不跳变；夹具与出入口录屏 |
| 模式 | 每种连续操作 ≥5 分钟；切换、移动、停止、相机、飞行落地有效 |
| 地图昼夜 | 玩家标记同步，12地标与7街区可搜索跳转，输入不触发驾驶，窗／路／车灯与水面同步 |
| 加载 | 未就绪不进入空场景，失败可重试，晚到请求不覆盖新目标；延迟／失败／连续跳转测试 |
| 流畅 | 预热后各模式5分钟采样，P95帧耗时 ≤33.3ms，60fps为优化目标；保留原始采样 |
| 冷启动 | 清缓存、50Mbps／80ms RTT，3次首次可操作中位数 ≤15秒；记录下载、构建、编译分项 |
| 稳定 | 连续30分钟无崩溃、黑屏、控制失效；区域往返10次，预热后资源计数不持续增长 |
| 发布 | 静态包独立运行，无缺失资源，游玩不调用公共地图API；来源与版本完整 |

自动化覆盖投影、排重、高度、道路方向与分层、碰撞、加载生命周期、跳转落点。视觉采用固定机位人工检查。性能目标不得在报告中悄悄降低。未通过项必须如实列出，不把技术试跑当成最终验收。
