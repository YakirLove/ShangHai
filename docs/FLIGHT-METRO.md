# 0.3.1 高空飞行与地铁入口

本轮继续本地开发，不发布线上，保留0.3.0归档。

## 飞行

直升机上限由380m提高为1200m，可飞越632m的上海中心模型。触顶清除向上的速度，按Q可正常下降；高空地点跳转保留当前高度，不再强制回到180m。E上升、Q下降，其他操作延续。

## 地铁

从固定的2026-10-23 OSM France上海PBF提取站点、站域及出入口，与[上海地铁官方逐线站名查询](https://service.shmetro.com/)核对1–18号线和浦江线。换乘按站名合并，上海市界内共410站，无参考站名缺漏；花桥、光明路、兆丰路在昆山，不作为本地开放点。市域机场线、未开通施工站和机场旅客捷运不纳入本次地铁入口清单。原始官方响应和哈希在data/source/metro/，OSM来源版本沿用data/source/citywide/。

每站一个代表入口，配红色M标识、站名灯箱、玻璃雨棚及可走入几米的门厅；只做地面入口示意，不包含乘车、站台和地下通行。313个入口使用OSM真实出入口坐标，97个由于现有建筑体量或空间限制在附近人行空间估算放置，最大距站点中心245.77m，均有来源标记。图上车站点保留站域WGS84坐标，入口点另存。官方GIS坐标未用于场景，避免混用坐标系产生偏移。

入口避开道路、水面、楼宇及地标保留区，随所属1km街区加载和释放；侧墙及后墙参与碰撞，正面通道保持开放。共享材质由场景持有，站名纹理和每块网格归加载块持有。

步行和骑行跳转使用代表入口中心。门厅拥有独立的地面路面采样，避免附近高架使步行角色落在桥面；汽车继续使用入口附近道路落点，车流不会驶入门厅。

地图上红色M表示地铁；可通过“M 地铁”图层开关控制显示。搜索支持站名、地铁、线路名；“地点 → M 地铁站查询”直接打开站点列表。选择站点可跳转到代表入口附近，高空飞行时保持高度。已有43个普通目的地保留。

## 重建与检查

完整重建仍使用`.venv/bin/python tools/build-data.py`，会先生成全市地理，再生成metro.json。只更新地铁数据可执行：

```sh
.venv/bin/python tools/build-metro.py
npm test
.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v
npm run build
```

`public/data/metro.json`为运行文件，`docs/metro-audit.json`记录覆盖、真实/估算入口数量及哈希。街区地理舍入可能形成自交多边形，入口选址时修复有效几何并保留内环，不改动原全市数据。工程与实机记录见`docs/acceptance/0.3.1/REPORT.md`。
