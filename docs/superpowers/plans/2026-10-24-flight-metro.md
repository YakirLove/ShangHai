# 高空飞行与地铁入口 Implementation Plan

> For agentic workers: 使用 superpowers:executing-plans，由当前Agent直接实现，不创建子任务。

**Goal:** 飞行最高1200m，全市地铁站具备真实点位、站名标志和可走入的简化入口。
**Architecture:** 新增独立metro.json和可重建地铁生成器；入口随城市块挂载和释放，地图/搜索使用站点列表。
**Tech Stack:** Three.js/WebGPU、Python/Pyosmium/Shapely、Node test、Tabbit。
**Spec:** docs/superpowers/specs/2026-10-24-flight-metro-design.md

## Global Constraints

- 本地开发，不发布；保留0.3.0归档与现有43目的地。
- 坐标采用既有WGS84转换；缺失的代表入口标记视觉估算。
- 同站换乘不重复建站；排除未开通、施工和废弃对象。
- 不增加实际地铁线路漫游、站台或乘车。

## Review Focus

- 上海市界外车站与未开通站不能误报已开放。
- 场景入口不能藏在建筑内部、放入道路或水面，也不能封死可走入通道。
- 站名纹理、普通Mesh绑定与碰撞在卸载后必须释放。
- 搜索输入不影响飞行；高空跳转、落地、触顶和下降不异常。
