# 上海全市扩展 Implementation Plan

> For agentic workers: use superpowers:executing-plans; 由当前 Agent 连续实现并验证，无需创建子任务。

**Goal:** 在本地将中心城区扩展为包含 16 区及主要岛屿的全市漫游。
**Architecture:** 固定全市 OSM 数据；保留中心城区覆盖层；静态城市块按需加载道路、地面、建筑及碰撞，简化全市地图与远景。
**Tech Stack:** Three.js / WebGPU、Vite、Python/Shapely/Pyosmium、Node test、Tabbit。
**Spec:** docs/superpowers/specs/2026-10-24-citywide-design.md

## Global Constraints

- 本地实现，不发布、不覆盖原 0.2.0 归档与线上版本。
- 保留 12 地标、19 目的地及 10 米双向隧道连续驾驶。
- 全市真实平面布局，估算高度和缺失数据明确记录。
- 区域及碰撞未就绪时禁止进入或跳转到空场景。

## Review Focus

- 岛屿和海面不能铺成陆地；水面内环与行政边界正确。
- 农田不被生成密集中心城区楼群。
- 全市落点加载竞态、失败重试、旧请求晚到保持原契约。
- 城市块与远景离开后释放，碰撞不能残留。
- 跨区到达、地图缩放和平移、隧道路面与模式切换保持可用。
