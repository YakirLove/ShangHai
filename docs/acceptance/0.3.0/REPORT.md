# 上海全市本地版 0.3.0 验收报告

状态：修复资源释放问题后的最终构建长时复测中，完成后写入最终结果。本轮只进行本地开发，没有发布或切换线上 0.2.0。

## 交付范围

上海市行政边界内 16 区与主要岛屿的基础场景，43 个可搜索目的地，保留中心城区 12 个专门制作地标和双向 10 米游戏洞宽的延安东路隧道。外围使用源道路、水系、农田、建筑轮廓及确定种子的程序补楼；机场、迪士尼、佘山等为周边道路落点，没有完整专用模型或内部场景。

外围高架净高、缺失楼高和地下高程是视觉估算，地形采用平地化处理；其他 1477 个地下道路对象因缺少洞体未开放，长江隧道未制作。岛屿可通过搜索或飞行到达，不以此报告宣称全市所有道路均已连续通车或逐条验证。中心城区历史缓存的方向及层级缺失继续标记。

## 来源与统计口径

全市 PBF 源头为 OSM France / OpenStreetMap contributors，头部时间戳 2026-10-23T02:06:05Z；SHA256 `dd18c877fa0d4c798a3a0d84eccae53aa73238754f7e62a68f79ff9684258706`，提供方 MD5 已匹配。市界及缺失的五区边界另有固定响应和哈希。中心城区沿用 2026-09-08 固定缓存。原始文件和构建方法随源码交付。

行政源几何约 16205.45 km²，包含管辖水域；扣除源水域后的几何陆域约 7148.98 km²。两者均不作为官方面积统计。约 30168.03 km² 的渲染包围框还含灰色未建模背景，不作为开放陆域面积。

数据含 188784 道路对象、117574 源建筑体量、455961 程序建筑体量及保留的 23652 个中心城区体量；数量不是官方真实唯一楼栋统计。30418 个 1 km 逻辑城市块，海域和空块部分内联，1485 块具有源农田图层。块数据约 329.44 MB；启动 city.json 约 7.73 MB。

## 验证条件

Apple M2 Pro、16 GB 内存；Tabbit 1.18.21.0 / Chromium 154，WebGPU，中档画质，实际渲染 1920×1080、renderer DPR=1。精确浏览器版本与设备记录见 hardware.json、cold-start.json。性能采样期间不构建、不录屏；隧道功能录屏单独进行。记录保留原始帧耗时与轨迹。

## 已完成检查

- Node 45/45、Python 地理与源完整性 3/3 通过。
- 核心区 32 个地理控制点最大坐标变换误差 2.2873m；四个隧道端部接缝高差 0。该精度核验仅针对核心区固定控制点，不能扩展解释为全市测绘精度。
- 69 个固定源道路检查方向、层级及节点属性；海岸夹具检查岛屿、入海口和水域，不把离岸道路作为填海依据。
- 步行与骑行入口门禁修复已通过单元及浏览器复测，汽车仍可进入地下坡道。
- 站点存储清理、HTTP 缓存绕过，本地三次可操作时间 2.155/1.739/1.601 秒，中位数 1.739 秒。
- 50 Mbps、80ms RTT 条件下三次可操作时间 4.208/4.278/4.275 秒，中位数 4.275 秒，满足15秒目标。浏览器/GPU着色器缓存保留；不含安装包下载或解压时间。每次启动实际本地资源传输约14.24 MB，全市块按需加载。
