# 0.3.1 实现自查

对照0.3.0源码归档检查控制器、主流程、城市块、地图、HTML/CSS、数据入口和打包脚本的实际差异，并完整阅读新增地铁数据、模型、碰撞及测试模块。自查未发现仍阻断本次交付的问题。

- 飞行控制器和应用跳转共用1200m上限；触顶取消向上速度，高空地标与地铁跳转保留高度。
- 地铁站点使用固定OSM WGS84，官方响应只用于名称与线路覆盖核对；换乘合并，昆山3站明确剔除。入口与站域点分开，97个估算入口没有标记为真实出入口。
- 入口正面开放，侧墙、后墙与顶板按高度参与碰撞。步行/骑行跳转使用入口中心和独立地面，汽车不使用门厅路面；车流与道路小地图仍只接收真实道路。
- 入口跟随所属城市块挂载。卸载保留已有Mesh dispose事件链，并释放每站纹理与材质、碰撞和路面索引。跨区往返的最后5次资源计数一致，见lifecycle.json。
- 410站搜索、跳转、符号挂载逐站检查；输入文字不驱动角色，地铁图层可切换。保留43个普通目的地。
- 构建资源相对寻址，metro.json、固定原始数据、许可及新生成器纳入交付包。当前0.3.1仅本地开发，未调用发布流程，保留0.3.0归档。

修复记录：初版6站出现高架或远处道路落点，已通过独立门厅路面修复并全量复验；测试夹具的初始化读取错误已保存诊断并修复，重新加载后实际步行检查通过。最终工程验证不等同于用户对新增外观的审美确认。

最终视觉复核修正M地铁按钮选中背景被更高优先级样式覆盖的问题。最终包与采样包的JavaScript字节哈希相同；源码包差异只有style.css，独立重建和页面检查已通过。
