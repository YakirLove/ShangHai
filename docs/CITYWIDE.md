# 上海全市本地版本 0.3.0

本轮按用户要求在本地继续开发，覆盖上海市行政范围及崇明、长兴、横沙等岛屿。线上 shanghai.datiaomao.com 继续保留此前发布的 0.2.0。

## 场景与数据

沿用中心城区 B 区的 12 个专门制作地标、19 个搜索目的地及双向 10 米游戏洞宽的延安东路隧道。扩展各区道路、水系与建筑，新增全市 16 区到达点及主要岛屿、虹桥、浦东机场周边、临港滴水湖、迪士尼周边和佘山周边。新增目的地为附近道路落点，机场、园区和山体没有内景或完整专用模型。

外围源文件为 [OSM France 上海 PBF](https://download.openstreetmap.fr/extracts/asia/china/)，快照时间 `2026-10-23T02:06:05Z`，本地 SHA-256 为 `dd18c877fa0d4c798a3a0d84eccae53aa73238754f7e62a68f79ff9684258706`，MD5 与提供方校验值一致。市界关系 913067 及部分缺失的区界由 OSM France polygons 服务补齐；原始响应、哈希与 URL 均保存在 `data/source/citywide/`。数据许可为 © OpenStreetMap contributors，ODbL 1.0。

全市原始对象包含 ID、方向、桥隧与层级信息，外围使用原始建筑轮廓形成的体量；没有高度时估算，缺少完整街区建筑时按确定种子补沿街体量。农田、公园、水面和源建筑周边作为排除区，远郊补楼密度更低。1485 个城市块另外绘制源农田多边形，绿地与农田不以裸地替代。原 B 区继续使用固定 2026-09-08 缓存作为优先覆盖，避免既有地标与过江线路变化。

海岸采用 OSM 的“左侧陆地、右侧水面”方向约定组装，保留无道路的小岛，不能因为海上有码头道路而把江口认成陆地。海岸与水域的来源几何并非官方测绘，几何计算面积与官方陆域统计口径不同；行政范围包含管辖水域，渲染包围框另含灰色未开放背景；加载门禁阻止进入市界外，均在数据审计中分别记录。

外围具备 bridge/layer 标签的道路以独立桥面表达，净高和坡道采用视觉估算。其他地下线路未制作洞体时不开放，已经验收的延安东路双向隧道保留。全市开放范围不代表每座桥隧均已逐条专项验收；没有把缺失数据改成地面跨水连接。车辆控制仍为原有自由漫游，不用于实际导航。

## 加载方式

- 1 km 城市块包含局部地面、水面、绿地、路面、楼宇、街景与碰撞，随玩家加载和释放；碰撞就绪后才允许到达或进入。
- 核心道路随启动包提供；外围道路表面索引随城市块注册和移除，全市地图使用单独简化的主干路。
- 高层远景使用合并实例，树木、行人和车辆使用固定容量的附近对象池。离开区域后释放实例缓冲、局部路牌纹理与碰撞数据。
- 空海域城市块使用离线内联描述，避免生成大量没有内容的请求。所有运行资源在包内，不依赖公共地图 API。
- 全市地图支持滚轮缩放、背景拖动平移、“全市”和“当前位置”；搜索包含区名，保留输入时不触发驾驶的保护。

## 本地构建

```sh
npm ci
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python tools/build-data.py
npm test
.venv/bin/python -m unittest discover -s tests -p test_citywide_geo.py -v
npm run build
npm run preview
```

完整构建只读固定本地源文件。`data/derived/` 是可再生成的中间缓存，不包含在源码归档；删除该目录会重新解析 PBF，核心 B 区也由固定源再生成。单独重建历史 B 区可使用 `--profile central-b`，会替换 public/data，因此日常继续开发使用默认全市构建。

交付与验证记录在 `docs/acceptance/0.3.0/`。原 0.2.0 源码包、静态包、验收证据及线上版本保留不变。
