# 0.3.2 真实启动进度与地图筛选

0.3.2已于2026-10-24发布至原独立域名https://shanghai.datiaomao.com/，0.3.1归档保留。发布和公网验证记录见docs/deployment/2026-10-24-0.3.2/REPORT.md。

## 启动

启动分为读取程序与地图、整理城市数据、准备图形引擎、构建城市场景、准备出发街区、准备光影与首帧6个步骤。百分比按这6步的实际完成量统计，表示启动任务进度，不代表剩余时间。下载显示实际已读取/总字节，场景显示完成批次，街区按挂载就绪数量，光影使用Three.js compileAsync的真实loaded/total回调；等待显卡或首帧时显示当前步骤和已用时间，不编造剩余秒数。

首帧实际渲染及GPU队列完成后才到100%并进入游戏。失败保留具体资源和“重新加载”按钮。场景构建分批让出主线程，使界面可刷新。启动前只呈现当前交通模式的角色。

小型bootstrap先显示进度，再按boot-manifest.json读取程序模块和3份基础JSON。Vite在构建时生成固定资源大小，以解码字节计数，避免压缩Content-Length造成错误百分比；截断或尺寸不匹配不视为完成。资源和数据均自托管。

## 地图

- 默认显示12个“地标建筑”，其余可选“地铁站”“城市地点”“全部地点”。这里的建筑指可搜索的专门制作地标，不为几十万普通楼宇增加密集标记。
- 地铁可选择1–18号线或浦江线；换乘站在各自线路中均可找到。可再叠加16个行政区与站名搜索。行政区按已有真实边界计算，不用线路名称冒充地区。
- 地图与列表同时遵循筛选；无结果时可清除筛选。线路菜单显示独立站点数量，列表说明所在区和换乘线路。
- 密集地点按屏幕距离聚合成数字点，点击后放大并在右侧列出成员；相同坐标也可从列表选择。标签避让，保持可读。
- 右下角＋/−放大缩小，⌖适配筛选结果；上方有“全市”和“当前位置”。支持滚轮、双击放大与拖动，搜索结果先保留至少2km的周边视野，手动放大可到250m。
- 点击标记或列表先查看详情，不立即移动。“飞到这里”会在目的地街区就绪后切换直升机并抵达附近空中（至少180m，保留更高飞行高度，最高1200m）；“按当前方式前往”保留当前交通方式。
- 请求失败保留位置和模式；旧请求不得覆盖新目的地。等待期间进入隧道也不能自动切换非汽车模式，需驶出后重试。

## 构建与验证

仍使用npm ci、npm test、npm run build，4187为生产预览。发布或复制静态包时必须保留boot-manifest.json、assets/和data/，HTML与启动清单使用重新验证缓存。

本轮没有改变原始地理数据或生成器。源码包客户端复现可运行：

```sh
node tools/audit-source.mjs docs/acceptance/0.3.2 --client-only
```

它在临时目录安装依赖、运行Node/Python测试、构建并逐文件对比全部静态输出；不会重新生成未变的全市地理。省略--client-only仍执行完整地理重建。实际截图、加载轨迹、地图/飞行验证和限制见docs/acceptance/0.3.2/REPORT.md。
